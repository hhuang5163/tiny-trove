# photos/

Drop figure photos here and Tiny Trove shows them automatically, so nobody has to upload anything in the app.

```
photos/<collection>/<series>/<figure>.jpg     (.png, .webp and .jpeg work too)
```

For example `photos/smiski/living/sunflower.jpg`. Every expected filename is listed in
[`smiski/FILENAMES.txt`](smiski/FILENAMES.txt).

- Square-ish photos look best. Around 600–1000 px wide is plenty.
- A figure with no photo shows a simple sketch instead.
- A photo added inside the app on a phone replaces the folder photo **on that phone only**.

**Heads up: everything in this folder is public.** GitHub Pages serves every file in the repo
to anyone who has the address, even if the repo itself is private. Use photos you took yourself.
Your collection (what you own, dates, notes, in-app photos) is never in this folder. It stays on your phone.
